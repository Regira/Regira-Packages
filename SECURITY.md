# Security policy

## Supported versions

The latest 6.x release line receives security fixes. Older versions are not maintained.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report privately:

- Email: [b2b@regira.com](mailto:b2b@regira.com) with subject `SECURITY`
- Or use GitHub's [private vulnerability reporting](https://github.com/Regira/Regira-Packages/security/advisories/new) on this repository

You will receive an acknowledgement within a few business days. Please include the package ID and version, a description of the issue, and a proof of concept if available. There is no bug-bounty program at this time.
