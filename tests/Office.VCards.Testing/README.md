# Office.VCards.Testing

Tests for [VCards.FolkerKinzel](../../src/VCards.FolkerKinzel/README.md): reading vCard 2.1 and 3.0 content,
writing 2.1, 3.0 and 4.0, and handling empty and invalid input, using the samples in `Samples/`. NUnit.

## Running

```bash
dotnet test tests/Office.VCards.Testing
```

No external requirements.
