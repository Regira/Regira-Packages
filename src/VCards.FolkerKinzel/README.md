# Regira.Office.VCards.FolkerKinzel

vCard backend for [Regira Office](https://regira.github.io/Regira-Packages/src/Common.Office/), built on [FolkerKinzel.VCards](https://www.nuget.org/packages/FolkerKinzel.VCards). `VCardManager` implements `IVCardService`, reading and writing vCard 2.1, 3.0 and 4.0 to and from the backend-agnostic `VCard` model.

## Installation

```xml
<PackageReference Include="Regira.Office.VCards.FolkerKinzel" Version="6.*" />
```

## Documentation

- [VCards](https://regira.github.io/Regira-Packages/src/Common.Office/docs/vcards/) — reading one or many contacts, writing with an explicit version, and the `VCard` model
